Cities, countries, and flights you add are saved automatically in this browser. Use these to back up your data or move it to another device.

Sync across devices

Connect a free Google Firebase project to keep this data in sync between your phone and desktop automatically. Everything still works offline without this — it's entirely optional.

How to set this up (one-time, ~5 minutes)
  1. Go to console.firebase.google.com and create a free project.
  2. In the project, open Build → Firestore Database and click "Create database" (start in test mode is fine to begin with).
  3. In Firestore's Rules tab, paste this and publish it: 
    rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /travelMapSync/{syncId} {
      allow read, write: if true;
    }
  }
}
    This keeps setup simple by skipping sign-in — treat your sync code below like a password, since anyone with it could read or write this document.
  4. Back in the project overview, click the </> (web) icon to register a web app, then copy the firebaseConfig object it shows you.
  5. Paste that config below, pick a sync code (any string only you know), and connect on both devices with the same code.
